# 🐉 Dragon Feast

### A Fun & Interactive 2D Game Built with Python & Pygame

**Dragon Feast** is a fun arcade-style game developed using **Python and Pygame**. The player controls a dragon, collects food, earns points, manages lives, and progresses through different game themes.

The project focuses on combining gameplay, graphics, sound effects, animations, and score management into a simple and engaging desktop game.

---

## 🎮 Game Features

* 🐉 Player-controlled Dragon
* 🍎 Food collection and scoring
* ❤️ 3 Lives system
* 🌈 3 different game themes
* ⭐ Score tracking
* 📈 Level progression
* 🔊 Background music and sound effects
* 💀 Game Over screen
* 🔄 Restart functionality
* 🏆 Winning state with animation
* 🎨 Custom font and graphical assets
* 💾 Score data stored using JSON

## 🎯 How to Play

The objective is simple:

**Control the dragon → Collect food → Increase your score → Survive → Progress through the game!**

The player starts with **3 lives**. Losing all lives results in Game Over.

Reach the required objective to reach the winning state and complete the game.

---

## 🎮 Controls

| Key            | Action     |
| -------------- | ---------- |
| ⬆️ Up Arrow    | Move Up    |
| ⬇️ Down Arrow  | Move Down  |
| ⬅️ Left Arrow  | Move Left  |
| ➡️ Right Arrow | Move Right |
| **R**          | Restart    |
| **ESC**        | Exit       |

## ▶️ How to Run

### 1. Install Python

Make sure **Python 3.x** is installed.

### 2. Install Pygame

```bash
pip install pygame
```

### 3. Run the Game

Open the project folder in VS Code or PowerShell and run:

```bash
python dragon_feast.py
```
